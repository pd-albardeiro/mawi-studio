# MAWI Studio

**MAWI — Modular Architecture for Worlds & Interaction**

A Linux-first 3D game creation studio inspired by Roblox Studio.

## Vision

MAWI Studio aims to provide a complete environment for creating
3D worlds, modeling objects, scripting gameplay with Luau,
testing game logic, and importing and exporting assets.

The long-term goal is to support workflows that allow projects
to be transferred to the official Roblox Studio on Windows.

## Planned Features

- 3D scene editor
- Object hierarchy and properties
- 3D modeling and transformations
- Luau scripting
- Physics and gameplay logic
- Asset import and export
- Scene and project management
- Performance-conscious design for Linux

## Project Status

Early development. Features and Roblox compatibility are not
yet implemented or guaranteed.
